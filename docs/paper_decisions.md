# Decision log for the RQ2 paper (OMol25 models at broken-symmetry transition states)

One entry per decision, newest at the bottom. Each entry says what was decided, what the
alternatives were, why, and which file or job the evidence is in. Open points are collected
at the end. Keep this file current: every decision that will have to be justified in the
paper's Methods section belongs here, with the date it was taken.

Vocabulary as in the thesis: closed-shell / broken-symmetry (groups), stable / unstable
(restricted solution), restricted / unrestricted surface, "level of theory" = functional and
basis only, "OMol25 protocol" = level + unrestricted + route to the broken-symmetry solution.
