# Metric definitions — v2 delta-head evaluation

Companion to `delta_head_v2_eval_numbers.json`. For every metric: what was measured, the exact
formula, and the source line that produced it. All definitions below were read off the generating
code, not inferred from the numbers.

**Scope.** Comparisons against CASSCF/NEVPT2 references (the OptTS geometry benchmark) are out of
scope and have been removed. The FOD-based MR stratification in Step 5 is retained — it groups the
benchmark reactions, it is not a comparison against a multireference method. CCSD(T) is retained
for the same reason: it is single-reference coupled cluster, not an MR method.

---

Two conventions recur and are easy to confuse, so they are named once here:

- **Macro-average** — compute the metric per reaction, then average the 30 per-reaction values.
  Every reaction carries weight 1/30 regardless of size.
- **Pooled** — concatenate all underlying samples across reactions, then compute the metric once.
  Large molecules carry more weight.

For energies the two coincide (every reaction contributes exactly 10 images). For forces they do
**not** (reactions differ in atom count). This is the source of the 138.9 vs 138.5 meV/Å pair
documented under Step 2.

## STEP 0 — Delta-head selection

**What was measured.** Which of three force-weight settings to carry forward, chosen on validation
loss before any benchmark reaction was touched.

The delta head predicts a per-atom scalar that sums to a molecular energy correction

```
Δ(R) = E[wB97M-V/def2-TZVP](R) − E[wB97X-D3/6-31G(d)](R)
```

Training loss is a two-term Huber objective

```
L = L_energy + force_weight · L_force
```

`val_e` and `val_f_f` are the two terms evaluated on the held-out validation split. The three runs
differ only in `force_weight`.

**Selection rule.** Lowest `val_f_f`.

| force_weight | val_e (Huber, eV) | val_f_f (Huber, eV/Å) | selected |
|---|---|---|---|
| 0.5 | 0.0109 | 0.0050 | |
| 1.0 | 0.0112 | 0.0039 | |
| **2.0** | 0.0112 | **0.0037** | ✓ |

**Dataset and model sizes**

| quantity | value |
|---|---|
| training geometries | **80,592** |
| training reactions | 4,997 (of 5,000 sampled; 3 dropped for < 15 geoms) |
| geometries per reaction | 20, stratified 4-segment around the TS |
| validation geometries | 10,600 |
| — with force labels | 2,240 |
| epochs to early stop | 130–138 (LR < 1e-6) |
| trainable parameters | **65,600** (head only; MACE frozen) |
| `MLP_IRREPS` | `64x0e` |
| input to head | `node_feats[:, 1024:]`, 16,384-dim |
| base model | `mace_t1x_p10_compiled.model`, all parameters frozen |

**Caveat that matters for reading the sweep table.** The three `val_e` values are 0.0109 / 0.0112 /
0.0112 eV — essentially tied — so the selection is effectively decided on the force term alone. The
total loss `L` is not comparable across rows, because `force_weight` appears inside it; a larger
`force_weight` inflates `L` mechanically. Do not rank the heads by total loss.

Training set: 80,592 geometries from 4,997 reactions. Validation: 10,600 geometries, of which 2,240
carry force labels — `val_f_f` is computed on that 2,240 subset only.

## STEP 1 — Energy at fixed geometry

**Source:** `pipeline/delta/eval_benchmark_sp_fw2.py`

**What was measured.** How well each method reproduces the *shape* of the wB97M-V energy profile
along a reaction path, with the geometries held fixed. No optimization happens here — every method
sees exactly the same 10 nuclear configurations, so this isolates energy accuracy from geometry
accuracy.

**Geometries.** The last 10 images written to `neb.db` by the converged ORCA wB97M-V/def2-TZVP
CI-NEB run (`eval_benchmark_sp_fw2.py:104-118`). 30 reactions × 10 images = 300 geometries.

**Anchoring — read this carefully.** Each method's profile is made relative to **its own first
image**, not to a common reference and not to the profile minimum:

```python
def rel(e): return (np.array(e) - np.array(e)[0]) * 1000   # line 215
```

So for method *m* and reaction *r*, the compared quantity is

```
ΔE_m,r(i) = [ E_m,r(i) − E_m,r(0) ] × 1000        i = 0 … 9,  units meV
```

Two consequences. First, any constant offset between levels of theory cancels exactly — this
metric is blind to absolute energy and measures only relative profile shape. Second, image 0
contributes an error that is identically zero for every method, so the mean below is effectively
over 9 informative points out of 10, and every method gets the same free correct answer. This
depresses all reported eMAE values by roughly a factor 9/10 relative to a metric over informative
points only.

**Per-reaction eMAE** (`eval_benchmark_sp_fw2.py:219-221`):

```
eMAE_m,r = (1/10) Σ_{i=0}^{9} | ΔE_m,r(i) − ΔE_wB97M-V,r(i) |
```

**Reported number.** Macro-average over the 30 reactions. Because image counts are equal, this
equals the pooled value; the two agree to the digit.

**Reference.** wB97M-V/def2-TZVP from `neb.db`. `wB97X-D3` is the true DFT value parsed from ORCA
EnGrad output (`parse_engrad`, line 63) — it is a *level-of-theory* baseline, not a model, and
answers "how much of MACE's error is inherited from its training level rather than from the fit".

**Results (meV):** MACE 107.6 · MACE+delta (v2, fw=2.0) 63.7 · wB97X-D3 94.9

### The 106 vs 63.7 question — resolved, not a conflict

| | eMAE MACE | eMAE delta | fMAE MACE | fMAE delta |
|---|---|---|---|---|
| v1 — `delta_head.pt`, `16x0e` | 107.6 | **105.8** | 138.9 | 133.8 |
| v2 — `delta_head_fw2.00.pt`, `64x0e` | 107.6 | **63.7** | 138.9 | 76.4 |

The bare-MACE columns are byte-identical across the two files, which is the expected control: the
frozen base model is the same, only the head changed. The doc's "106" is v1's 105.8. Both numbers
are correct for their own head. Nothing needs flagging — the v1 figures simply must not be quoted
as v2.

### bias and R²

Definitions, both verified by reproducing the v1 doc values exactly before being applied to v2:

- **bias** — pooled signed mean error over all 300 image-0-anchored points:
  `bias = mean( ΔE_pred − ΔE_ref )`
- **R²** — computed *within each reaction*, then averaged over the 30:
  `R²_r = 1 − Σ_i (pred_i − ref_i)² / Σ_i (ref_i − mean(ref))²`, reported as `mean_r R²_r`

**v2 values** (from `eval_benchmark_sp_fw2_full.json`):

| method | bias (meV) | R² |
|---|---|---|
| MACE | +77.4 | 0.9734 |
| **MACE+delta** | **−3.9** | **0.9899** |
| wB97X-D3 | +84.8 | 0.9781 |

v1 was delta bias −5.0, R² 0.9672 — so the bias correction is essentially unchanged between heads,
while R² improves markedly. Applying the same code to the v1 file reproduced the doc's +77 / −5 and
0.973 / 0.967 to the digit, which is what validates the definitions above.

The R² definition matters — the alternatives do not reproduce the doc. Pooled `1 − SSR/SST` gives
0.9866 / 0.9851; pooled Pearson r² gives 0.9907 / 0.9856. Any thesis text quoting these must state
that R² is a per-reaction average, or the number cannot be reproduced.

Note also that this R² is **not a goodness-of-fit of a fitted line**. No line is fitted; it compares
predictions against the identity. A negative value is therefore possible and would mean "worse than
predicting the reaction's mean energy".

To get v2 bias/R², `eval_benchmark_sp_fw2.py` must be re-run with the per-image arrays added to the
output dict (lines 241-249) — the geometries and checkpoint both still exist.

## STEP 2 — Forces at fixed geometry

**Source:** `pipeline/delta/eval_benchmark_sp_fw2.py:163-166`

**What was measured.** Accuracy of the force vectors on the same 300 fixed geometries. Forces, not
energies, are what drives a geometry optimization, so this is the quantity most directly predictive
of NEB behaviour.

**How the delta forces are obtained.** Not finite differences — the correction is differentiated
analytically through the head (`eval_benchmark_sp_fw2.py:146`):

```python
delta_f_all = -torch.autograd.grad(per_struct.sum(), bd2['positions'])[0]
f_delta = f_mace + delta_f_all
```

so `f_delta` is a true analytic gradient of the corrected energy surface and is conservative by
construction.

**Formula.** Per image, the mean absolute error over **every force component** (all atoms × 3
Cartesian directions), then averaged over the 10 images:

```
fMAE_m,r = (1/10) Σ_i  mean_{a,c} | F_m(i,a,c) − F_wB97M-V(i,a,c) |     × 1000  meV/Å
```

This is a per-component error, **not** a per-atom vector-norm error. A per-atom norm convention
would give a systematically larger number (roughly √3 × for isotropic errors); the two must not be
mixed when comparing against literature values.

**Reported number and the 138.9/138.5 pair.** The JSON row stores the per-reaction value; I
macro-averaged those to get **138.9 / 76.4** meV/Å. The benchmark doc reports **138.5 / 76.0**,
which is the *pooled* figure printed at `eval_benchmark_sp_fw2.py:259-261` — it concatenates all
error components across all reactions (`all_fe_mace`) and takes one mean, weighting each reaction by
its atom count. Both are correct for their own convention; the gap is 0.4 meV/Å. Pick one and say
which. Macro-average is the more defensible choice here, since the benchmark deliberately samples
30 reactions as equal units.

**Cosine similarity.** The widely-quoted 0.324 → 0.412 pair is **v1**: the table it comes from
(`delta_head.md:126-129`) lists it beside force MAE **134** meV/Å, which is v1's 133.8, not v2's
76.4. The v2 values are:

| method | cosine vs wB97M-V |
|---|---|
| MACE | 0.3223 |
| **MACE+delta** | **0.5134** |
| wB97X-D3 | 0.3216 |

So the improvement is larger than v1 suggested — 0.32 → 0.51, not 0.32 → 0.41.

Note that wB97X-D3's own cosine (0.3216) is essentially identical to MACE's (0.3223): MACE
faithfully reproduces its training level's force directions, and the delta head is what moves them
toward wB97M-V. That is a useful sanity check on the whole delta-learning premise.

The convention is recorded in `pipeline/_analyze_benchmark_full.py:81-95`:

```python
norm_p = np.linalg.norm(fp, axis=1)      # per-atom vector norms, fp is (N,3)
norm_r = np.linalg.norm(fr, axis=1)
valid  = (norm_p > 1e-6) & (norm_r > 1e-6)
dots   = np.sum(fp[valid] * fr[valid], axis=1)
cos    = dots / (norm_p[valid] * norm_r[valid])
```

So it is a **per-atom** cosine — the angle between each atom's predicted and reference 3-vector —
averaged over all valid atoms across all images, **not** a cosine between flattened 3N vectors.
Atoms with force magnitude below 1e-6 eV/Å are skipped in both structures, which matters because
near-zero forces have ill-defined directions and would otherwise inject noise.

One caveat on reading cosine values across Parts I and II: it discriminates well when errors are
large (the delta head, 0.32 → 0.51) but poorly when they are small. See Part II — the OMol25 models
score ~0.84 despite force MAEs an order of magnitude better than anything here, because their
residual error concentrates on near-zero-force atoms where direction is ill-defined.

## STEP 3a — Barriers at fixed geometry, vs wB97M-V

**Source:** `pipeline/_collect_uma_m_and_fw2_barriers.py:30-41`

**What was measured.** The single number a chemist actually wants — the forward activation barrier —
evaluated with geometries still held fixed at the ORCA path.

```python
e = np.array(all_e[-10:])
rel = (e - e[0]) * 1000
fwd = float(rel.max())          # forward barrier, meV
rev = float(fwd - rel[-1])      # reverse barrier, meV
```

So:

```
E_a,fwd = max_i [ E(i) − E(0) ]           image 0 treated as the reactant
E_a,rev = E_a,fwd − [ E(9) − E(0) ]       = max_i E(i) − E(9)
```

**Two caveats this definition carries.**

1. The barrier is the maximum **over a discrete 10-image band**, not an interpolated or optimized
   saddle. The true saddle generally sits between images, so every method's barrier is biased
   *low* by the same discretization. Because all methods share the geometries here, the bias
   largely cancels in the comparison — but the absolute values are not saddle-point barriers.
2. Images 0 and 9 are taken as reactant and product. They are NEB band endpoints, which are relaxed
   minima only to the tolerance the endpoint relaxation reached.

**Reported statistics**, over the 30 reactions, per method, against `neb_wb97m_fwd_meV`:

```
bias = mean_r ( E_a,method(r) − E_a,ref(r) )      signed — direction of systematic error
MAE  = mean_r | E_a,method(r) − E_a,ref(r) |      magnitude
```

Both are macro-averages over reactions.

**v2 results** (regenerated; the original `delta_fwd_meV` field was v1 — see version provenance):

| method | bias (meV) | MAE (meV) |
|---|---|---|
| MACE | +114.1 | 168.4 |
| **MACE+delta** | **−33.6** | **124.3** |
| wB97X-D3 | +148.2 | 151.3 |

By tier, MAE: high — MACE 81.2, delta 150.9; mid — 254.0, 135.8; low — 169.8, 86.4. Note that on
the high tier bare MACE still beats the corrected model, as it did under v1.

## STEP 3b — Barriers at fixed geometry, vs CCSD(T)

Identical extraction to Step 3a; only the reference changes, to `ccsdt_fwd_meV` — CCSD(T)/def2-TZVP
single points computed on the same fixed ORCA geometries.

**Why both 3a and 3b exist.** They answer different questions. Step 3a asks "does the model
reproduce the DFT it was corrected toward" — an interpolation question, where wB97M-V is by
definition perfect. Step 3b asks "does it reproduce reality" — where wB97M-V is itself an
approximation and appears as one competitor among others. A method can win 3a and lose 3b.

CCSD(T) is present for all 30 reactions, not only the high-MR tier. Note that CCSD(T) is a
single-reference method, so on the high-MR tier — the reactions selected precisely for
multireference character — it is the least trustworthy exactly where it is most needed. Treat the
high-tier CCSD(T) comparison as the weakest cell in the table.

**v2 results** (regenerated):

| method | bias (meV) | MAE (meV) |
|---|---|---|
| MACE | +197.7 | 226.0 |
| **MACE+delta** | **+50.0** | **141.7** |
| wB97M-V NEB | +83.6 | **103.8** |
| wB97X-D3 | +231.8 | 231.8 |

By tier, MAE: high — MACE 238.8, delta 175.5, wB97M-V 225.8; mid — 260.0, 146.8, 58.4; low —
179.0, 102.8, 27.3.

**Reading the bias/MAE ratio.** wB97X-D3 sits at exactly 231.8/231.8 = 1.00, meaning every one of
the 30 reactions errs in the same direction — pure systematic functional error, no scatter. MACE
inherits most of that (0.87). After correction the delta head drops to 0.35: the systematic
component is largely gone and what remains is reaction-to-reaction variance the head cannot predict.
That is the honest characterisation — **the head fixes the offset, not the variance.**

**Scoring against the achievable ceiling.** The head is trained to reproduce wB97M-V, so wB97M-V's
own error against CCSD(T) (103.8 meV) is the floor it can reach, not zero. MACE starts at 226.0, so
the available improvement is 122.2 meV; the head delivers 84.3 of it — **69% of what was
achievable**. That is a more meaningful statement than the raw 226 → 142.

⚠ On the high tier, MACE+delta (175.5) appears to *beat* wB97M-V itself (225.8). Do not build an
argument on this. It cannot reflect skill — the head cannot systematically outperform its own
training target — and arises because CCSD(T) is a single-reference yardstick that is least reliable
on exactly these reactions, plus incidental error cancellation.

## STEP 4 — NEB-driven evaluation

Everything above froze the geometries. This step lets each model **find its own reaction path**,
which is the realistic use case and a strictly harder test: geometry errors and energy errors now
compound.

**Protocol** (`pipeline/mace_delta_neb.py:199-234`): endpoints relaxed with BFGS to fmax = 0.05
eV/Å; 10-image band initialized from the T1x wB97X-D3 path; plain NEB to fmax = 0.15
(`method='improvedtangent'`); then `climb=True` and CI-NEB to fmax = 0.05; 500-step cap; ODE
optimizer (`NEBOptimizer`) by default.

**Barriers.** Extracted from the model's own final band by the same `max(E(i) − E(0))` rule as Step
3a, then compared against the ORCA wB97M-V band and against CCSD(T).

|---|---|---|---|---|
| MACE bare | +69.1 | **164.7** | +152.7 | 212.2 |
| MACE+delta | −117.1 | 173.6 | −33.5 | **167.6** |

**The two references disagree about which wins.** Against wB97M-V, bare MACE is marginally better

### Optimisation cost — and a correction to the "15.9×" figure

`mace_delta_neb_benchmark.md` reports that the delta head needs **15.9× more NEB iterations**. That
number reproduces exactly, but it is a **mean of per-reaction ratios**, and it is dominated by
reactions where bare MACE converged in 1–4 steps:

| statistic | value |
|---|---|
| mean of per-reaction ratios | **15.93×** ← the quoted figure |
| median per-reaction ratio | **2.18×** |
| ratio of total steps (5,352 / 4,142) | **1.29×** |
| reactions where delta needs more steps | **25 / 30** |

rxn1962 alone contributes a ratio of 221× (1 step → 221), rxn9246 86×, rxn4063 62×. Dividing by a
one-step denominator inflates the mean without describing typical behaviour.

The directional claim is solid — delta needs more steps in 25 of 30 reactions — but quote the
median (2.18×) or the total (1.29×), not 15.9×.

**Convergence is not the discriminator.** Both methods write 30/30 markers and reach 24/30 strict
(fmax ≤ 0.05). Five of the six step-limited reactions are the *same* for both (rxn7949, rxn7937,
rxn1061, rxn4004, rxn4500); bare additionally fails rxn1154, delta rxn4060. So the step-limited
cases are a property of those reactions, not of the correction. The head makes optimisation slower,
not more likely to fail.

### Convergence — corrected

The `delta_fw2_neb_fmax` field is **not** the optimizer's convergence criterion, and my earlier
"3/30 converged" reading of it was wrong. It comes from `mace_delta_neb.py:221`:

```python
relax_neb.attach(lambda: fmaxs.append(neb_tools.get_fmax()))
```

`NEBTools.get_fmax()` internally constructs a **fresh `NEB(self.images)` using default kwargs** —
`climb=False`, `method='aseneb'` — while the band actually being optimized at that moment has
`climb=True` and `method='improvedtangent'`. The recorded value is therefore a plain-NEB,
aseneb-tangent diagnostic of the final CI-NEB band, computed under a different force model than the
one the optimizer tested.

It is biased upward precisely *when CI-NEB succeeds*: the climbing image has its spring force
removed and its parallel force component inverted, so it deliberately ends up unevenly spaced;
recomputing with `climb=False` restores a large spring force on that image. The observed
distribution is consistent with this — mean 0.0688, tight range 0.042–0.143, no long tail, whereas
genuinely stalled optimizations would scatter widely.

The real convergence record is the `converged` marker file (`mace_delta_neb.py:229`) and the last
`NEBOptimizer` line of `neb.log`, parsed by `last_fmax()` in `pipeline/analyse_neb.py:28`. Both live
on the cluster under `mace_delta_neb_results_fw2/<rxn>/` and were never copied down —
`_collect_uma_m_and_fw2_barriers.py:40` took `fmaxs.json[-1]` instead. **Convergence is therefore
undetermined from local data.** One pass over the cluster counting marker files settles it.

This also means the delta fmax values are not comparable to the ORCA pipeline's convergence
statistics, which use the optimizer's own logged value.

### RMSD — Kabsch, on transition-state geometries

**Source:** `pipeline/_ts_rmsd_fw2_remote.py:17-24`

```python
def kabsch_rmsd(P, Q):
    P = P - P.mean(axis=0); Q = Q - Q.mean(axis=0)
    H = P.T @ Q
    U, S, Vt = np.linalg.svd(H)
    d = np.linalg.det(Vt.T @ U.T)
    R = Vt.T @ np.diag([1.0, 1.0, d]) @ U.T
    return float(np.sqrt(np.mean(np.sum(((P @ R.T) - Q)**2, axis=1))))
```

Both structures are centred on their centroid, then the optimal rotation is found by SVD of the
covariance matrix, with `diag(1,1,d)` enforcing a proper rotation (det = +1) so reflections are
excluded — a mirror image is correctly scored as different, not as identical. The returned value is

```
RMSD = sqrt( (1/N) Σ_a | R·p_a − q_a |² )        Å
```

**Limitation.** Atom order is assumed to correspond between the two files; no permutation matching
is performed. This is safe here because all structures descend from a common T1x band and retain its
atom ordering, but the metric would be wrong for independently generated structures.

**Which TS.** The `transition_state.xyz` written by each NEB run, i.e. the highest-energy image of

## STEP 5 — Stratification by multireference character

**What the tiers are.** All 30 benchmark reactions were ranked by FOD (fractional occupation number
weighted density) analysis — PBE/def2-SVP at T_el = 5000 K, N_FOD = Σ|n_i − n⁰_i|, following Grimme
& Hansen. Higher N_FOD indicates stronger multireference character, i.e. reactions where a single
Slater determinant is a poor description.

- **high** — FOD ranks 1–10 (strongest MR character)
- **mid** — ranks 11–20
- **low** — ranks 21–30

**How stratified values were computed.** Reactions were grouped by the `group` field in
`full_benchmark_results.json`, and each Step 1/2/3a/3b/4 metric recomputed within the group using
exactly the formula given above for that metric. No metric definition changes between tiers — only
the reaction subset. Each tier has n = 10.

## PART II — Fixed-geometry comparison against OMol25 models (RKS-stable subset)

**Source:** `pipeline/delta/eval_sp_rks_stable.py` · **Output:** `eval_sp_rks_stable.json` · job 10693089

Everything above compares MACE and MACE+delta against DFT. This part adds the three OMol25-trained
universal models — UMA-S, UMA-M, eSEN — on identical geometries, closing the gap noted earlier
where those models had NEB-driven numbers but no fixed-geometry numbers.

### Why this reaction set

The 22 reactions were chosen because **the restricted Kohn–Sham (RKS) solution is the stable SCF
solution** for them — no broken-symmetry (UKS/BS) instability. The consequence is that the
wB97M-V/def2-TZVP reference is free of spin-symmetry-breaking pathology: the closed-shell single
determinant is a genuine description, not an artefact of a constrained wavefunction.

That matters because UMA and eSEN are trained on **OMol25**, which is closed-shell RKS data at
ωB97M-V/def2-TZVPD. On a reaction where RKS is unstable, an OMol25 model would be asked to
reproduce a reference its training distribution cannot represent, and failure would say nothing
about the model. Restricting to RKS-stable reactions makes this **a fair test of model quality
rather than a probe of multireference character** — which is what the FOD-stratified benchmark in
Part I was for.

The 22 are the intersection of the RKS-stable set with the original 30-reaction benchmark, so
wB97M-V NEB geometries and wB97X-D3 EnGrad single points already existed for every one.

| tier | n | reactions |
|---|---|---|
| high | 4 | rxn7945, rxn7937, rxn1150, rxn0896 |
| mid | 8 | rxn1154, rxn4513, rxn7955, rxn4519, rxn4500, rxn2553, rxn8829, rxn1155 |
| low | 10 | rxn9246, rxn4498, rxn1061, rxn4003, rxn4004, rxn4063, rxn4114, rxn4060, rxn1961, rxn1962 |

⚠ **rxn0896 is `mid` in the original FOD grouping but `high` here.** RKS stability and FOD rank are
different axes; the RKS-stable assignment is used throughout Part II. Four reactions from the
original list (rxn7936, rxn0101, rxn10005, rxn10054) were excluded as they come from the next-HIGH
set and have different data provenance.

### Method and metrics

Identical geometries for all seven methods: the last 10 images of each converged ORCA wB97M-V
CI-NEB band — the same geometries as Part I. 22 × 10 = 220 structures.

Metric definitions are **unchanged** from Steps 1–2: eMAE on image-0-anchored self-referenced
profiles, force MAE per Cartesian component, per-atom cosine with |F| < 1e-6 skipped, all
macro-averaged over reactions.

**Charge and spin are not set explicitly** — fairchem's OMol25 defaults (neutral, closed-shell
singlet) are used, identical to `uma_neb.py` and `esen_neb.py`, so these numbers remain comparable
with the existing NEB results. The run logs a warning to this effect per structure. For an
RKS-stable, neutral, closed-shell set this default is the physically correct choice, but it is a
default rather than an assertion, and should be stated as such.

### The consistency check

Compare UMA-S against wB97X-D3 with the true functional gap (wB97X-D3 vs wB97M-V):

| | UMA-S vs wB97X-D3 | wB97X-D3 vs wB97M-V |
|---|---|---|
| eMAE | 99.4 | 98.8 |
| fMAE | 131.1 | 130.9 |
| cosine | 0.296 | 0.300 |

Identical within noise on all three, and the same holds for UMA-M and eSEN. UMA's disagreement with

near it. The mirror image holds for MACE against its own training level (41.5 meV, cosine 0.955).

**Each model reproduces the level of theory it was trained on.** That is the cleanest statement of
the result, and it validates the RKS-stability premise: with no BS instability, the OMol25 models
recover the reference essentially exactly.

### Interpretation and caveats

**This is not an architecture comparison.** UMA and eSEN are trained on OMol25 at
ωB97M-V/def2-TZVPD — essentially the reference level — so they are evaluated *in distribution*.
MACE is trained at wB97X-D3/6-31G(d) and asked to transfer to a level it never saw, with the delta
head as the bridge. The comparison measures **what the training data buys you**, not which
architecture is better. Framed that way it is the more useful result: for wB97M-V accuracy,
training on wB97M-V-level data closes ~95% of the gap where the delta head closes 43%.

**Basis mismatch, in the models' disfavour.** OMol25 uses def2-TZVP**D**; the reference here is
def2-TZVP. The diffuse functions differ. The models reach ~5 meV despite that mismatch.

**Cosine is a poor discriminator in this regime.** UMA's 0.837 looks worse than MACE's
0.955-against-its-own-level despite 3× better force MAE. Once errors become small, the residual
concentrates on near-zero-force atoms whose direction is ill-defined, and the 1e-6 cutoff is
permissive. Lead with fMAE for these models; cosine was informative for the delta head
(0.32 → 0.51) because errors there are large.

**Unverified: training-set overlap.** OMol25 is large and covers organic reaction chemistry. Whether
it contains these T1x reactions or close analogues has not been checked. T1x is a separate dataset
at a different level of theory, so direct contamination is unlikely, but "unlikely" is not "checked",
and a ~5 meV agreement is strong enough that the question deserves an explicit answer before
publication.

## Summary of definitional choices that change reported numbers

| Choice | Convention used | Alternative | Effect |
|---|---|---|---|
| Energy anchor | image 0, per-method self-anchored | profile minimum | cancels constant offsets; image 0 error identically 0 |
| eMAE aggregation | macro-average over reactions | pooled | identical here (equal image counts) |
| fMAE aggregation | macro-average → 138.9 / 76.4 | pooled → 138.5 / 76.0 | 0.4 meV/Å |
| Force error | per Cartesian component | per-atom vector norm | norm convention ≈ √3 larger |
| R² | per-reaction, then averaged → 0.973 | pooled 1−SSR/SST → 0.987 | 0.014 |
| Barrier | max over 10 discrete images | interpolated saddle | all methods biased low |
| RMSD | Kabsch, proper rotation, fixed atom order | permutation-matched | none here |
| Cosine similarity | per-atom 3-vector, skip \|F\| < 1e-6 | flattened 3N vector | different quantity |
